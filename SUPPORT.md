# Support

Thanks for using Polaris. Here is where to get help.

## Documentation

- **Quickstart & guides:** `docs/` (start with `README.md`, then
  `docs/CONFIGURATION.md`, `docs/API_REFERENCE.md`).
- **Feature guides:** routing/failover, `docs/GUARDRAILS.md`,
  `docs/SEMANTIC_CACHE.md`, `docs/MCP.md`, `docs/PROVIDERS.md`.
- **SDK:** `pkg/client` (Go) — see the package docs on pkg.go.dev.

## Questions and discussion

- Open a **GitHub Discussion** for how-to questions, ideas, and design feedback.

## Bugs and feature requests

- Open a **GitHub Issue** using the appropriate template (bug report, feature
  request, or provider request).
- For a bug, include your Polaris version, config (with secrets redacted), and
  reproduction steps.

## Security

- Do **not** file public issues for security problems. See `SECURITY.md`.

## Commercial / production help

Polaris is community-maintained open source under Apache-2.0. There is no
commercial SLA; production adopters should pin a release, run the documented
reliability configuration, and monitor the shipped Prometheus metrics.
